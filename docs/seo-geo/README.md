# SEO, GEO, dan WebMCP Koma

## Arsitektur dan kebijakan indeks
- URL resmi `https://ruangkoma.web.id`; metadata dan JSON-LD WebSite/Organization ada di `src/app/layout.tsx`. Coretan yang lolos kebijakan mempunyai metadata unik dan JSON-LD DiscussionForumPosting/SocialMediaPosting di `src/app/coretan/[id]/page.tsx`.
- Publikasi **bukan** izin indeks. `search_consent` pada tabel `posts` sudah ada, default `false` untuk data lama dan baru. Tidak perlu migrasi tambahan. Penulis memberikan izin melalui kotak pilihan composer; hanya posting yang `published`, tidak tersembunyi, disetujui pencarian, tidak dilaporkan, bukan tulisan AI, cukup substansial, tidak mengandung tautan/PII/sinyal sensitif, tanpa gambar unggahan, dan tidak duplikat yang masuk arsip/sitemap/metadata indeks. Aturan di `src/lib/search-policy.ts`; penentuan dilakukan saat permintaan, tanpa cache halaman pengguna. Ini gerbang konservatif, bukan jaminan keamanan atau pengindeksan.
- Edit menghapus izin; pelaporan/moderasi mengeluarkan tulisan dari indeks; hapus mengembalikan 404. Penulis dapat mencabut izin di permalink lewat `PUT /api/posts/[id]` dengan `{ "withdrawSearch": true }`, diotorisasi menggunakan sesi/kunci rahasia penulis. Pengembalian izin setelah edit tidak otomatis tersedia: tulis ulang coretan jika ingin meminta izin baru. Penghapusan dari indeks eksternal bergantung pada jadwal recrawl mesin pencari; untuk mendesak, gunakan alat penghapusan resmi penyedia.
- Arsip SSR `/jelajah/arsip?page=N` menggunakan tautan next/previous; parameter invalid/di luar rentang 404, page 1 hanya di URL kanonik tanpa parameter. `/jelajah` dan pencarian `?q=` tidak diindeks sebab hasilnya bisa memuat coretan publik tanpa izin pencarian. Sitemap dinamis memuat halaman statis serta hanya arsip dan coretan yang layak; tidak mengirim `lastmod` yang tidak pasti. URL post tidak ditampilkan dalam structured data bila tidak layak. Perubahan privasi tidak ditahan oleh service worker (`public/sw.js` hanya menyimpan fallback offline).

## AI discovery / WebMCP
- `robots.txt` mengizinkan Googlebot, Bingbot, OAI-SearchBot, PerplexityBot mengakses laman publik; menolak GPTBot, Google-Extended, ClaudeBot, CCBot (pelatihan). Admin/API/pesan dibatasi. Aturan robots bukan kontrol autentikasi: visibilitas server tetap diverifikasi. Cek Cloudflare/WAF produksi secara terpisah dengan log terverifikasi karena kebijakan edge bisa berbeda.
- `public/llms.txt` memuat identitas, aturan, kebijakan privasi, dan tautan yang memang ada; tidak memuat coretan pribadi atau salinan konten.
- Form pencarian `/jelajah` menggunakan WebMCP deklaratif `toolname=search_public_coretan`, `tooldescription`, dan `toolparamdescription` untuk parameter `q` (teks, maksimal 100 karakter). Submit memakai GET `/jelajah?q=...` baik di peramban biasa maupun pada WebMCP yang mendukung anotasi; React melanjutkan pencarian yang sudah ada. Tanpa `toolautosubmit`, browser pendukung WebMCP meminta pemeriksaan manual sebelum submit. Tidak ada tool tulis. Browser WebMCP yang masih eksperimental perlu diuji ulang pada versi rilis pengguna; tidak menyatakan dukungan umum.
- ARD `/.well-known/ard.json` dan path kompatibilitas `/.well-known/ai-catalog.json` memuat satu resource nyata: panduan baca-saja `public/agents/koma-public-guide/SKILL.md` untuk lima halaman resmi. Keduanya tidak mencantumkan coretan pengguna, API, atau aksi tulis/hapus/moderasi/admin. Discovery melalui `<link rel="ard">` di layout; berkas ini tidak mengubah kebijakan indeks coretan maupun izin penggunaan kontennya. WebMCP tetap tersedia hanya di form pencarian `/jelajah` pada browser yang mendukungnya; status Not Applicable pada browser tanpa dukungan WebMCP bukan kegagalan situs.

## Admin dan integrasi eksternal
- Dashboard analitik yang ada menampilkan kelayakan lokal, bukan jumlah halaman terindeks. Endpoint `/api/admin/analytics` tetap butuh autentikasi admin dan kini dapat menarik Google Search Console (kueri, halaman, klik, impresi, CTR, sitemap dan angka indeks jika tersedia) serta Bing Webmaster (trafik/peringkat agregat 30 hari). Baca-saja; respons `private, no-store`, waktu tunggu 8 detik dan empty/error state jujur. Tidak menyimpan kata pencarian atau token dalam telemetri.
- Opsional: `GOOGLE_SEARCH_CONSOLE_PROPERTY` harus cocok dengan properti terverifikasi dan `GOOGLE_SEARCH_CONSOLE_ACCESS_TOKEN` adalah token OAuth scope `webmasters.readonly` **berumur pendek**; operator harus mengelola rotasinya di secret manager. `BING_WEBMASTER_API_KEY` butuh akses properti Bing. Semua hanya di environment server; tidak ada fallback kredensial. Verifikasi token, kepemilikan properti, bentuk respons Bing, dan pengiriman sitemap di produksi masih **tertunda** sampai kredensial diberikan. Tanpa kredensial tidak ada angka yang diisi.
- Google AI Overviews/AI Mode dan Bing Copilot tidak punya penghitung sitasi terpisah dalam integrasi ini. Trafik rujukan AI, crawl error, dan error structured data tidak dipalsukan: telemetri Koma tidak merekam referrer; pemeriksaan tersebut membutuhkan sumber resmi/izin yang belum tersedia.

## Verifikasi
- `npx tsc --noEmit`, `npm test`, `npx tsx --test tests/test-seo-geo.ts tests/test-search-policy.ts`, dan `npm run build` lulus di lingkungan lokal. `npm run test:all` kini melewati tes integrasi setelah dua asersi lama disesuaikan dengan moderasi fail-closed, tetapi masih gagal pada satu asersi admin yang mengharuskan URL gambar QRIS selalu terkonfigurasi meski pengaturan QRIS bersifat opsional; konfigurasi donasi tidak diubah. Build Next 14 menjalankan lint + pemeriksaan tipe; tidak ada skrip lint terpisah. Tes HTTP statis robots.txt dan llms.txt merespons 200; endpoint admin tanpa autentikasi merespons 401. Beranda muncul di browser lokal. Uji browser/HTTP `/jelajah`, arsip, sitemap, dan permalink pada `next start` tanpa PostgreSQL merespons 500 karena konfigurasi produksi wajib database; tidak mengalihkan ke data lokal untuk menghindari konten yang salah. Tes WebMCP browser eksperimental, akses bot melalui edge produksi, inspeksi URL indeks dan metrik Search Console/Bing harus diverifikasi sesudah deployment dan pemberian akses.
